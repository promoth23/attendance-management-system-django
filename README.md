# Student Attendance Management System

A comprehensive Django-based Student Attendance Management System designed to manage students, staff, courses, subjects, attendance records, and administrative operations.

## Features

* Admin Dashboard
* Student Management
* Staff Management
* Course Management
* Subject Management
* Attendance Tracking
* Attendance Reports
* Role-Based Authentication
* Password Reset Functionality
* Responsive UI using AdminLTE

## Technology Stack

* Python 3.11
* Django 3.1.1
* SQLite
* HTML
* CSS
* JavaScript
* Bootstrap
* AdminLTE

## Installation

```bash
git clone https://github.com/promoth23/attendance-management-system-django.git
cd attendance-management-system-django
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```

Use your configured admin credentials to access the system.
